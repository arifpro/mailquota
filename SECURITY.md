# Security Policy

## Supported versions

Only the latest published minor version receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/arifpro/mailquota/security/advisories/new).
Include the affected version, a description of the impact, and steps to reproduce.

You can expect an acknowledgement within 7 days. Fixes are released as a patch version,
and the advisory is published once a fixed version is available.
